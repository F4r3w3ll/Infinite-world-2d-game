# Infinite-world-2d-game
A 2D game with an infinite world where your goal is to collect as many coins as possible while enemies continuously chase you. The longer you survive, the more enemies spawn.


## Requirements

- Python 3.10+
- Pygame
- Noise

```bash
pip install pygame noise
```

## Running the game

```bash
git clone <repo-url>
cd Infinite-world-2d-game
python main.py
```

## Controls

| Key       | Action                  |
|-----------|-------------------------|
| A / D     | Move left / right       |
| Space     | Jump                    |
| O / P     | Fade in / Fade out music|
| ESC       | Close game              |
