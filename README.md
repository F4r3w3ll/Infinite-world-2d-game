# Infinite-world-2d-game
2D game with infinite world, with radanom world generation. Made in Python. In progress.


## Requirements

- Python 3.10+
- Pygame

```bash
pip install pygame
```

## Running the game

```bash
git clone <repo-url>
cd 2D_Game
python main.py
```

## Controls

| Key       | Action                  |
|-----------|-------------------------|
| A / D     | Move left / right       |
| Space     | Jump                    |
