# Infinite-world-2d-game
2D game with infinite world, with radanom world generation. Made in Python. In progress.


## Requirements

- Python 3.10+
- Pygame
- Noise

```bash
pip install pygame noise
```

## Running the game

```bash
git clone <repo-url>
cd Infinite-world-2d-game
python main.py
```

## Controls

| Key       | Action                  |
|-----------|-------------------------|
| A / D     | Move left / right       |
| Space     | Jump                    |
